# Clean Your TV — उपयोगकर्ता मार्गदर्शिका

No-root और Root अलग-अलग टीवी सेटअप के लिए समान दर्जे के विकल्प हैं। LG Developer Mode के लिए No-root चुनें या पहले से root SSH पहुँच होने पर Root चुनें। संगतता और किए गए परीक्षणों का दायरा हर संस्करण के लिए अलग है।

## स्थापना से पहले

यह मार्गदर्शिका **[v1.2.0 स्थिर संस्करण](https://github.com/Razdva122/clean-your-tv-lg-webos/releases/tag/v1.2.0)** के लिए है। `releases/latest/download` लिंक प्रकाशित स्थिर संस्करण देते हैं। [स्थापना](../INSTALL.md) और [रिलीज़ विवरण](../RELEASE-1.2.0.md) देखें।

रिलीज़ के संस्करण: cytv **0.3.1**, Home **1.4.1**, Home Helper **0.6.19**, Root **0.3.0**, Home Updater और Root Updater **0.2.1**, Android **0.2.1-preview** (कोड **10**), System Updater पर्यवेक्षक **1.0.0**, प्रोटोकॉल **1**।

टीवी चालू रखें और कंप्यूटर को उसी भरोसेमंद स्थानीय नेटवर्क से जोड़ें। बाद में कंप्यूटर बंद रह सकता है। अनुकूलता मॉडल, फ़र्मवेयर और रिमोट पर निर्भर है। Root के लिए वास्तविक उपकरण पर कुछ जाँच बाकी हैं।

- **No-root:** LG Developer Mode और Key Server चालू करें। टीवी पर दिखाया पासफ़्रेज़ भरें और टीवी पर आने वाला अलग पेयरिंग अनुरोध स्वीकार करें। Developer Mode सक्रिय रहना चाहिए; अवधि समाप्त होने पर इस तरीके से लगाए ऐप हट सकते हैं। Beta नवीनीकरण चालू होने पर भी आधिकारिक टाइमर देखें। Helper की निगरानी के लिए स्थानीय नेटवर्क चाहिए।

अपडेट किए गए No-root Helper के लिए टीवी पर Node.js 0.12.2 या नया संस्करण आवश्यक है। इंस्टॉलर स्थापना से पहले टीवी रनटाइम की जाँच करता है। पहले प्रकाशित पैकेजों को यह अनुकूलता अपने आप नहीं मिलती; हर मॉडल पर इनपुट डिवाइस की पहुँच, स्टैंडबाय से वापसी और कोल्ड बूट की जाँच आवश्यक है।

- **Root:** पहले से काम करता root SSH प्रवेश आवश्यक है। इंस्टॉलर टीवी को root नहीं करता। पहले से root किए टीवी पर Developer Mode चालू न करें। root प्रवेश और पुनर्प्राप्ति सेवाएँ उपलब्ध रखें।


## Developer Mode सेटअप (No-root)

Developer Mode से CYTV बिना root वाले TV पर ऐप इंस्टॉल कर सकता है।

1. TV पर LG Apps खोलें, Developer Mode खोजें और इंस्टॉल करें।
2. Developer Mode खोलें और अपने LG Developer खाते से साइन इन करें। ज़रूरत हो तो webostv.developer.lge.com पर खाता बनाएँ।
3. Dev Mode Status चालू करें। TV फिर से शुरू होगा। उसके बाद Developer Mode दोबारा खोलें।
4. Key Server चालू करें और Developer Mode खुला रखें। वहाँ दिखा IP Address ही CYTV में डालने वाला TV का पता है।
5. TV के Developer Mode में दिखे छह अक्षरों वाला Passphrase डालें। बड़े और छोटे अक्षर जैसे दिखें वैसे ही लिखें।

LG खाते का पासवर्ड नहीं, TV पर दिखा कोड डालें। कोड न दिखे तो Key Server चालू करें।

पेयरिंग अलग चरण है: TV पर अनुरोध आने पर रिमोट से CYTV को अनुमति दें।

Developer Mode चालू रखें: समय खत्म होने से पहले इसे खोलें और TV के इंटरनेट से जुड़े होने पर EXTEND दबाएँ। समय खत्म होने पर LG ये ऐप हटा सकता है।

Home आपके ऐप की स्क्रीन है। Home Helper से Home बटन दबाने पर यह स्क्रीन खुलती है।

इंस्टॉल होने पर Home दबाकर देखें। LG Home खुले तो TV की ऐप सूची से Home Helper खोलें। दो सेकंड में Home तीन बार छोटा दबाने से LG Home खुलता है। Home नियंत्रण फिर शुरू करने के लिए Home Helper खोलें, Helper शुरू करें चुनें और पुष्टि करें। चुनी हुई Home स्क्रीन बनी रहती है।

[LG Developer Mode](https://webostv.developer.lge.com/develop/getting-started/developer-mode-app)

## Root के लिए वैकल्पिक Python

Root को टीवी पर Python 3.9 या नया चाहिए। इंस्टॉलर केवल संस्करण संख्या नहीं देखता: वह `json`, `fcntl`, लॉक, फ़ाइलों और उपप्रक्रियाओं सहित ज़रूरी मॉड्यूल और कार्यों की वास्तविक जाँच करता है। मौजूदा इंटरप्रेटर उपयुक्त हो तो दूसरा Python डाउनलोड नहीं होता। अन्यथा सेटअप के दौरान कंप्यूटर या Android, तय URL, आकार और SHA-256 वाला **ARMv7 soft-float CPython 3.13.17** डाउनलोड करके पहले से भरोसेमंद SSH कनेक्शन से टीवी तक भेज सकता है। सामान्य डेस्कटॉप/Android इंस्टॉलर में यह अतिरिक्त संग्रह शामिल नहीं है। इस चरण में टीवी को इंटरनेट नहीं चाहिए।

वैकल्पिक डाउनलोड लगभग **26.3 MB**, सामान्यीकृत SSH स्थानांतरण **51.5 MB** और स्थापित फ़ाइलें **119.3 MB** हैं। तैयारी के लिए टीवी पर **320 MiB** खाली जगह चाहिए। सक्रिय करने से पहले लोडर और लाइब्रेरी की संगतता जाँची जाती है। रनटाइम `/var/lib/clean-your-tv-python/` के निजी संस्करण स्लॉट में रहता है; सिस्टम Python, libc और वैश्विक PATH नहीं बदलते। Root/System Updater के लिए अब भी root, उपयुक्त webOS सेवाएँ और Node.js **8+** चाहिए; No-root Helper को Node.js **0.12.2+** चाहिए।

इंटरनेट वाले कंप्यूटर पर टीवी खोजे या उससे जुड़े बिना सत्यापित कैश तैयार करें:

```sh
./cytv --prepare-python-runtime --data-dir /path/to/private-cache
```

स्थापना के समय वही `--data-dir` उपयोग करें। कैश ले जाने के लिए अलग निजी फ़ोल्डर बनाएँ, जिसमें आपकी सामान्य SSH कुंजियाँ या प्रोफ़ाइल न हों। `status`, `doctor`, `restore` और `uninstall` अपने आप Python डाउनलोड नहीं करते। ऐप हटाने के बाद भी Root, अपडेटर या पुनर्प्राप्ति में काम आ रहे रनटाइम स्लॉट रखें। विवरण: [वैकल्पिक रनटाइम](../OPTIONAL-PYTHON.md)।

## स्थापना और भाषा

- **Windows x64:** `cytv-windows-x64-desktop.zip` डाउनलोड करें, फ़ाइल एक्सप्लोरर में **Extract All** चुनें, फिर `cytv-desktop/cytv-desktop.exe` खोलें। `_internal` फ़ोल्डर उसके साथ रखें। Windows प्रकाशक हस्ताक्षर कॉन्फ़िगर नहीं है। अलग कंसोल `cytv-windows-x64.exe` है; नीचे के PowerShell आदेशों के लिए इसका नाम `cytv.exe` रखें और `.\cytv.exe` चलाएँ।
- **macOS 13 या नया:** Apple Silicon के लिए `cytv-macos-arm64.zip`, Intel के लिए `cytv-macos-x64.zip` खोलें। `cytv.app` को Applications में रखें और खोलें। स्थानीय नेटवर्क की अनुमति दें। भरोसेमंद डाउनलोड रुकने पर Privacy & Security → Open Anyway चुनें; Gatekeeper बंद न करें। पुराने सिस्टम की जाँच पूरी नहीं हुई है।
- **Linux x64:** Ubuntu 22.04+, Debian 12+ या Mint 21+ पर `cytv-linux-x64.deb` को ग्राफ़िकल पैकेज प्रबंधक से स्थापित करें और ऐप मेनू से Clean Your TV खोलें। लाइब्रेरी के लिए इंटरनेट लग सकता है। Linux ARM पैकेज नहीं है। अलग `cytv-linux-x64` निष्पादन फ़ाइल CLI है; ग्राफ़िकल ऐप के लिए `.deb` लें।

[Android इंस्टॉलर](../../android/README.md) में इंटरफ़ेस की सभी दस भाषाएँ उपलब्ध हैं। ऊपर दाईं ओर वर्तमान भाषा दिखती है; दूसरी भाषा चुनने के लिए उस पर टैप करें। आपकी पसंद फ़ोन पर सहेजी जाती है।

Android पर कनेक्शन के दौरान चुनी गई रखरखाव कार्रवाई दिखती रहती है और उसी की प्रगति दिखाई जाती है। फ़ोन के सिस्टम फ़ॉन्ट के साथ लेबल और सहायता पाठ बड़े किए गए हैं।

डेस्कटॉप सहायक शुरू में सिस्टम की भाषा चुनता है और आपकी चुनी भाषा सहेजता है। टीवी पर **सेटिंग्स → भाषा** में भाषा चुनें या टीवी की भाषा अपनाने वाला स्वचालित विकल्प चुनें। इंस्टॉलर और टीवी की भाषा सेटिंग अलग हैं। कोड [भाषा सूची](../LANGUAGES.md) में हैं।

macOS/Linux पर अलग से डाउनलोड की CLI के लिए, निकाली गई फ़ाइलों के फ़ोल्डर में:

```sh
chmod +x cytv
./cytv --language hi install
```

टीवी चुनें या उसका IP भरें, संस्करण चुनें और सारांश जाँचें। नई SSH पहचान केवल भरोसेमंद नेटवर्क पर अपने टीवी के लिए स्वीकार करें; सहेजी गई कुंजी बदलने पर प्रवेश रुकता है। Root पुनर्प्राप्ति तैयार करके Home तुरंत चालू करता है; परीक्षण अवधि या बनाए रखने की पुष्टि नहीं है। दिशा बटन, OK, Home, वापस/रद्द, आवाज़, स्टैंडबाय से वापसी और पूरी बिजली बंद करके दोबारा चालू करने की जाँच करें।

Root हटाना रुक जाए तो ऐप में फिर हटाएँ चुनें। ऐप जारी रखने से पहले टीवी के सुरक्षित रिकॉर्ड और पैकेज की स्थिति जाँचता है; पूरा हो चुका हटाना दोबारा नहीं भेजता। काम चल रहा हो तो एक मिनट प्रतीक्षा करें। परिणाम सत्यापित न हो सके तो टीवी पुनः चालू करके फिर जाँचें; सहायता के लिए निदान रिपोर्ट सुरक्षित रखें।

## उपयोग और पुनर्प्राप्ति

दिशा बटन से चुनें, OK से खोलें; क्रम बदलने के लिए OK दबाए रखें। वापस का छोटा दबाव ऐप का नेविगेशन और बाहर निकलने की पुष्टि बनाए रखता है। Home नियंत्रण चालू हो तो छोटा Home लॉन्चर खोलता है। नए बिल्ड में वापस बटन 1.2 सेकंड दबाए रखने से LG Home एक बार खुलता है। Home नियंत्रण का स्विच और आपकी सेटिंग्स नहीं बदलते।

**नए बिल्ड: दो सेकंड में Home तीन बार दबाएँ**, हर बार बटन छोड़ें। इससे पसंद मिटाए बिना LG Home लौटता है और नियंत्रण रुकता है। पुराने No-root Helper 0.6.13 तक इसके बजाय Home लगभग दो सेकंड दबाए रखें। Home दबाए रखना Root की आपातकालीन क्रिया नहीं है।

No-root: दो सेकंड में Home तीन बार छोटा दबाने से LG Home खुलता है। Home नियंत्रण फिर शुरू करने के लिए Home Helper खोलें, Helper शुरू करें चुनें और पुष्टि करें। चुनी हुई Home स्क्रीन बनी रहती है। Root: फिर शुरू करने के लिए Home सेटिंग्स में **Home बदलें** चालू करें। **LG Home खोलें** से Home का गंतव्य बदले बिना LG Home एक बार खुलता है। LG Home को स्थायी गंतव्य बनाने के लिए **Home बदलें** बंद करें या `cytv restore` चलाएँ। दोनों नियंत्रक एक साथ न चलाएँ। समस्या दोबारा हो तो LG Home चालू रहने दें।

```sh
./cytv --language hi status
./cytv --language hi doctor --report
./cytv --language hi restore
./cytv --language hi uninstall
```

रुकावट के बाद दोबारा प्रयास से पहले `status` चलाएँ और लॉग रखें। `restore` ऐप हटाए बिना LG Home लौटाता है; `uninstall` हटाने से पहले बहाल करता है। Root पुनर्प्राप्ति डेटा जानबूझकर रखा जाता है; दोबारा स्थापना मजबूर करने के लिए उसे न मिटाएँ। रिपोर्ट साझा करने से पहले देखें; कुंजियाँ या प्रोफ़ाइल फ़ोल्डर प्रकाशित न करें।

## अपडेट और हटाना

कनेक्ट होने पर cytv स्थापित → शामिल संस्करण दिखाता है और पहली स्थापना, पुनः स्थापना तथा पुराने संस्करण पर जाने में अंतर बताता है। पुष्टि से पहले सारांश पढ़ें; `--yes` संगतता जाँच नहीं हटाता। काम करने वाले पैकेज और सेटिंग्स की निजी प्रतियाँ रखें। कंप्यूटर से पैकेज बदलने से पहले No-root Helper रोकें; पहले अनइंस्टॉल न करें। चालू Root पर केवल एक IPK न चढ़ाएँ: cytv की तय प्रक्रिया अपनाएँ। कंप्यूटर ऐप हटाने से टीवी ऐप नहीं हटते।

उम्मीदवार में सेटिंग्स → सॉफ़्टवेयर अपडेट में **सभी अपडेट करें** जुड़ता है। स्वतंत्र System Updater संस्करण के लिए हस्ताक्षरित रिलीज़ समूह जाँचता है: root वाले टीवी पर No-root के लिए Home, Helper और Home Updater; Root के लिए Root Home, Root Updater और Home नियंत्रण/पुनर्प्राप्ति रनटाइम। टीवी से स्थापना के लिए **root, Homebrew Channel**, उपयुक्त Python, Node.js 8+ और काम करती webOS इंस्टॉलर सेवाएँ चाहिए। बिना root वाले टीवी पर कंप्यूटर उपयोग करें।

नई स्थापना में उम्मीदवार के पूरे इंस्टॉलर से Home और उस संस्करण का पुनर्प्राप्ति Updater तैयार करें। यह संक्रमण संस्करण स्थिर अपडेट फ़ीड पर उपलब्ध नहीं है।

अगर Root पहले से स्थापित है और Root Updater मौजूद है, तो सामान्य पुनः स्थापना जानबूझकर रोकी जा सकती है। पहले `status` और निदान चलाएँ, फिर मौजूदा Updater में लेन-देन और पुनर्प्राप्ति की स्थिति देखें। चल रही या अनिश्चित कार्रवाई को उसी पुराने संस्करण की उपयुक्त पुनर्प्राप्ति प्रक्रिया से सुलझाएँ; नए बुनियादी ढाँचे में बदलाव का निर्णय टीवी की वास्तविक स्थापित स्थिति देखकर लेना होगा। रिकॉर्ड न मिटाएँ और `--yes`, अकेली IPK या पुराने OTA से रोक न लाँघें। केवल ऐप बदलने वाला OTA नया बुनियादी ढाँचा स्थापित नहीं करता। [मौजूदा टीवी की जाँच](../UPDATES.md#one-time-computer-preparation) अपनाएँ।

Home `systemUpdateProtocol = 1` और उपयुक्त पुनर्प्राप्ति Updater वाली संगत व्यवस्था सत्यापित होने के बाद ही कंप्यूटर से पर्यवेक्षक चालू करें। इंस्टॉलर में टीवी के सभी घटकों के अपडेट चालू करने वाला विकल्प चुनें। Root के लिए सहेजे हुए root SSH कनेक्शन के साथ:

```sh
./cytv --language hi enable-system-updates --edition root --host TV_ADDRESS
```

root वाले टीवी की No-root स्थापना में पहले कंप्यूटर से Home/Helper/Home Updater तैयार करें, फिर [अपडेट निर्देशों की root SSH उपनाम प्रक्रिया](../UPDATES.md#one-time-computer-preparation) अपनाएँ। पर्यवेक्षक वास्तव में स्थापित घटकों का सत्यापित पुनर्प्राप्ति आधार सहेजता है। केवल ऐप बदलने वाला पुराना OTA नया Python रनटाइम, पर्यवेक्षक या अपडेटर का बुनियादी ढाँचा स्थापित नहीं करता। तैयारी के बाद साझा अपडेट प्रक्रिया उपयोग करें; टकराने वाले पुराने इंस्टॉलर रोके जाते हैं।

स्थापना से पहले पुष्टि ली जाती है, फिर स्टार्टअप अपने आप जाँचा जाता है। प्रोफ़ाइल और सेटिंग्स सहेजी जाती हैं; उपयोगकर्ता द्वारा या आपात तरीके से बंद किया गया Home नियंत्रण अपने आप चालू नहीं होता। ऊपर/नीचे से बदलाव पढ़ें और बाएँ/दाएँ से स्थिर कार्रवाई बटन चुनें; स्थिति ताज़ा होने पर रिमोट का चयन बना रहता है। नारंगी बिंदु नया संस्करण बताता है, भले ही उसके लिए कंप्यूटर चाहिए। स्थिति और उपलब्ध पुराने संस्करण के लिए Updater में पुनर्प्राप्ति खोलें। सिस्टम वापसी पूरा पिछला घटक समूह और सहेजी हुई प्रोफ़ाइल बहाल करती है; अपडेट के बाद किए सेटिंग बदलाव खो सकते हैं। स्वचालित स्टार्टअप जाँच वापसी का विकल्प नहीं मिटाती; वह अगली लेन-देन प्रक्रिया तक रहता है।

रुकावट के बाद `status` चलाएँ और लेन-देन रिकॉर्ड तथा पुनर्प्राप्ति डेटा रखें। अनिश्चित परिणाम पर पुनः स्थापना और वापसी रुकती हैं; केवल संस्करण पढ़ लेना इंस्टॉलर पूरा होने का प्रमाण नहीं है। दोबारा प्रयास मजबूर करने के लिए रिकॉर्ड, लॉक या Python स्लॉट न मिटाएँ। `doctor --report` हर असफल Root आवश्यकता अलग दिखाता है और क्रेडेंशियल या कच्चे आउटपुट के बिना संख्यात्मक SSH निकास कोड रखता है। साझा करने से पहले रिपोर्ट देखें।

लिए है, ब्राउज़र संग्रह या पुराने बुनियादी ढाँचे के स्थानांतरण के लिए नहीं।

रुकावट के बाद पहले स्थिति देखें। जारी रखने का विकल्प केवल मूल स्नैपशॉट, कार्य
स्वामित्व और साबित अंतिम स्थिति पर मिलता है। अन्य चरणों में स्थिति, बहाली या निदान
करें; स्रोत CLI कुछ अन्य पहचाने गए चरण स्पष्ट रूप से जारी कर सकता है। cytv का
Finish Root setup अधूरी कार्य प्रक्रिया फिर शुरू नहीं करता। जर्नल न मिटाएँ और बिना
जाँच फिर प्रयास न करें। Homebrew केवल Installer अपडेट करता है; उत्पाद के अपडेट
मौजूदा Updater और हस्ताक्षरित पूर्ण सेट से होते हैं। केवल Installer हटाने पर उत्पाद
रहता है। स्पष्ट पूर्ण हटाने से LG Home बहाल होता है और अपने स्टार्टअप लिंक हटते हैं;
स्वतंत्र पुनर्प्राप्ति प्रमाण, संग्रह और जरूरी Python स्लॉट सुरक्षित रहते हैं।
इस रास्ते के सभी वास्तविक TV परीक्षण बाकी हैं। C3 पर पुराने Root 0.2.0 के परिणाम
Homebrew स्थापना को प्रमाणित नहीं करते।

स्टार्टअप स्वामित्व रसीदों से जुड़े निजी स्क्रिप्ट से होता है। पैकेज की पहचान केवल डेटा के रूप में जाँची जाती है; उसके स्टार्टअप स्क्रिप्ट नहीं चलते। पैकेज गायब या असुरक्षित होने पर अपने-आप दोबारा शुरू होना रुकता है; स्वतंत्र रिकवरी से LG Home फिर भी वापस लाया जा सकता है। जाँच के समय सत्यापित फ़ाइलों की अस्थायी निजी कॉपी बन सकती है, पर Home या उत्पाद नहीं बदलता।
