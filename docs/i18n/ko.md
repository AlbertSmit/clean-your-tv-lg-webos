# Clean Your TV — 사용자 안내

## 설치 전 준비

이 안내서는 설치, 일상적인 사용 및 복구를 다룹니다. 언어 선택과 macOS/Linux 데스크톱 앱은 [v0.10.3](https://github.com/Razdva122/clean-your-tv-lg-webos/releases/tag/v0.10.3)에 포함되어 있습니다. 이전 v0.9.0 다운로드에는 데스크톱 앱이 없습니다. 두 에디션의 [설치 안내](../INSTALL.md)를 확인하세요.

TV를 켜고 컴퓨터와 같은 신뢰할 수 있는 로컬 네트워크에 연결하세요. 설치 후에는 컴퓨터를 꺼도 됩니다. 호환성은 모델, 펌웨어, 리모컨에 따라 다릅니다. Root는 아직 미리 보기 단계이며 실제 기기 검증이 남아 있습니다.

- **No-root:** LG Developer Mode와 Key Server를 켜세요. TV에 표시된 암호 문구를 입력하고 별도로 표시되는 페어링 요청을 TV에서 승인하세요. Developer Mode를 계속 활성화해야 합니다. 세션이 만료되면 설치한 앱이 삭제될 수 있습니다. 베타 자동 갱신을 켰더라도 공식 타이머를 확인하세요. Helper의 상태 감시에는 로컬 네트워크가 필요합니다.
- **Root:** 기존 root SSH 접근 권한이 필요합니다. 설치 프로그램은 TV를 루팅하지 않습니다. 이미 루팅한 TV에는 Developer Mode를 켜지 마세요. root 접근 및 복구 서비스를 유지하세요.

## 설치와 언어 선택

- **Windows x64:** 콘솔 패키지를 풀고 `cytv.exe`를 여세요. PowerShell에서는 아래 명령의 `./cytv`를 `.\cytv.exe`로 바꾸세요. Windows용 그래픽 앱은 포함되지 않습니다.
- **macOS 13 이상:** Apple Silicon은 `cytv-macos-arm64.zip`, Intel은 `cytv-macos-x64.zip`을 푸세요. `cytv.app`을 응용 프로그램 폴더로 옮겨 열고 로컬 네트워크 접근을 허용하세요. 신뢰할 수 있는 다운로드가 차단되면 개인정보 보호 및 보안 → 확인 없이 열기를 사용하세요. Gatekeeper를 끄지 마세요. 구형 시스템 검증은 완료되지 않았습니다.
- **Linux x64:** Ubuntu 22.04 이상, Debian 12 이상 또는 Mint 21 이상에서 `cytv-linux-x64.deb`를 그래픽 패키지 관리자로 설치하고 앱 메뉴에서 Clean Your TV를 여세요. 라이브러리 설치에 인터넷이 필요할 수 있습니다. Linux ARM 패키지는 없습니다.

데스크톱 설치 마법사는 처음에 시스템 언어를 사용하고 직접 선택한 언어를 저장합니다. TV에서는 **설정 → 언어**에서 언어를 고르거나 시스템 언어를 따르는 자동 옵션을 선택하세요. 설치 프로그램과 TV의 언어 설정은 별개입니다. 지원 코드는 [언어 목록](../LANGUAGES.md)을 참조하세요.

macOS/Linux에서 별도로 받은 CLI는 압축을 푼 폴더에서 실행하세요.

```sh
chmod +x cytv
./cytv --language ko install
```

TV를 선택하거나 IP를 입력하고 에디션과 설치 요약을 확인하세요. 새로운 SSH 신원은 신뢰할 수 있는 네트워크의 본인 TV인 경우에만 승인하세요. 저장된 키가 바뀌면 접근이 차단됩니다. Root는 복구 기능을 준비한 뒤 시험 기간이나 유지 확인 없이 Home을 바로 활성화합니다. 방향키, OK, Home, 뒤로/취소, 음량, 대기 모드 복귀와 전원을 완전히 껐다 켜는 동작을 확인하세요.

## 사용과 복구

방향키로 선택하고 OK로 실행합니다. OK를 길게 눌러 순서를 바꿉니다. 뒤로를 짧게 누르면 앱의 탐색과 종료 확인이 유지됩니다. Home 제어가 활성화되면 짧은 Home으로 런처를 엽니다. 새 빌드에서는 뒤로를 1.2초 동안 누르면 LG Home이 한 번 열립니다. Home 제어 스위치와 설정은 바뀌지 않습니다.

**새 빌드에서는 2초 안에 Home을 세 번 짧게 누르세요.** 매번 버튼을 놓아야 합니다. 설정을 지우지 않고 LG Home으로 복귀하며 Home 제어를 중지합니다. No-root Helper 0.6.13 이하에서는 대신 Home을 약 2초 동안 누릅니다. Home 길게 누르기는 Root의 비상 복구 동작이 아닙니다.

No-root는 LG 앱 목록에서 **Home Helper**를 열어 재개하세요. Home만 열어서는 중지가 해제되지 않습니다. Root는 Home 설정에서 **Home 변경**을 켜서 재개하세요. **LG Home 열기**는 Home의 연결 대상을 바꾸지 않고 LG Home을 한 번 엽니다. LG Home을 계속 사용할 기본 대상으로 복원하려면 **Home 변경**을 끄거나 `cytv restore`를 실행하세요. 두 제어 프로그램을 동시에 실행하지 마세요. 문제가 반복되면 LG Home을 유지하세요.

```sh
./cytv --language ko status
./cytv --language ko doctor --report
./cytv --language ko restore
./cytv --language ko uninstall
```

작업이 중단되면 재시도 전에 `status`를 실행하고 로그를 보관하세요. `restore`는 앱을 삭제하지 않고 LG Home을 복구합니다. `uninstall`은 복구 후 제거합니다. Root 복구 데이터는 의도적으로 남습니다. 재설치를 강제하려고 삭제하지 마세요. 진단 보고서는 공유 전에 검토하고 키나 프로필 폴더는 공개하지 마세요.

## 업데이트와 제거

정상 동작하는 패키지와 개인 설정 백업을 보관하세요. No-root Helper를 중지한 뒤 컴퓨터에서 패키지를 업데이트하세요. 먼저 제거하면 설정이 지워질 수 있습니다. cytv의 통합 Root 설치는 설정 → 소프트웨어 업데이트에서 호환 릴리스의 업데이트를 지원하지만 수동 Root 설치에는 다른 제한이 있습니다. 실행 중인 Root 환경에 개별 IPK를 덮어쓰지 마세요. 재설치에는 cytv의 명시적인 재설치 절차를 사용하세요. 컴퓨터 앱을 제거해도 TV 앱은 제거되지 않습니다.

영문 기술 안내: [데스크톱](../DESKTOP_INSTALL.md), [CLI](../CLI.md), [No-root](../INSTALL.md), [수동 설치](../MANUAL_INSTALL.md), [복구](../RECOVERY.md), [에디션 비교](../EDITIONS.md).

연결 후 cytv는 TV에 설치된 버전을 읽고 Home 및 Home Helper(No-root) 또는 Root 및 Root Updater의 현재 버전 → 설치 프로그램에 포함된 버전을 표시합니다. 설치 전에 버전을 검토하고 확인하세요. 최초 설치, 재설치, 이전 버전으로 변경이 구분됩니다. `--yes`는 확인을 건너뛰지만 버전은 계속 표시합니다.

소프트웨어 업데이트에는 설치된 버전 또는 더 최신 버전의 정보만 표시됩니다. 복구를 열면 저장된 복원 버전이나 복원이 불가능한 이유를 볼 수 있습니다. 뒤로를 누르면 업데이트로 돌아갑니다.
