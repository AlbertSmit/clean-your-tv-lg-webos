Стабильный выпуск принят с этим ограниченным объёмом проверки; другие модели не подтверждены.

Включите телевизор и подключите компьютер к той же доверенной локальной сети. После установки компьютер можно выключать. Совместимость зависит от модели, прошивки и пульта; для Root остаются незавершённые проверки на оборудовании.

- **No-root:** включите LG Developer Mode и Key Server. Введите кодовую фразу с экрана телевизора и отдельно подтвердите на телевизоре запрос сопряжения. Developer Mode должен оставаться активным: после истечения сессии установленные таким способом приложения могут удалиться. Следите за официальным таймером даже при включённом продлении Beta. Для мониторинга Helper нужна локальная сеть.

Обновлённому No-root Helper нужен Node.js 0.12.2 или новее на телевизоре. Установщик проверяет runtime до установки. Ранее опубликованные пакеты не получают эту совместимость автоматически; доступ к устройствам пульта, выход из standby и холодный запуск нужно проверить на каждой модели.

- **Root:** требуется уже работающий root-доступ по SSH. Установщик не получает root. Не включайте Developer Mode поверх существующей root-конфигурации. Сохраняйте доступ по SSH и работоспособность служб восстановления.


## Настройка Developer Mode (No-root)

Developer Mode позволяет CYTV установить приложения на телевизор без root.

1. На телевизоре откройте LG Apps, найдите Developer Mode и установите это приложение.
2. Откройте Developer Mode и войдите в аккаунт LG Developer. Если аккаунта нет, создайте его на webostv.developer.lge.com.
3. Включите Dev Mode Status. Телевизор перезагрузится. После этого снова откройте Developer Mode.
4. Включите Key Server и оставьте Developer Mode открытым. В поле IP Address указан адрес телевизора для ввода в CYTV.
5. Введите Passphrase — код из шести символов на экране Developer Mode на телевизоре. Соблюдайте регистр букв.

Нужен код с экрана ТВ, а не пароль аккаунта LG. Если кода нет, включите Key Server.

Сопряжение — отдельный шаг: когда телевизор покажет запрос, разрешите подключение CYTV с пульта.

Следите за таймером Developer Mode: до его окончания откройте приложение и нажмите EXTEND при подключённом интернете. Если время истечёт, LG может удалить эти приложения.

Home — экран с вашими приложениями. Home Helper нужен, чтобы открывать его кнопкой Home на пульте.

После установки нажмите Home для проверки. Если открылся LG Home, запустите Home Helper из списка приложений телевизора. Трижды коротко нажмите Home за две секунды, чтобы вернуться в LG Home. Для возобновления откройте Home Helper, выберите «Запустить Helper» и подтвердите. Сохранённый выбор главного экрана не изменится.

На компьютере CYTV показывает подготовку по одному шагу. «Подробности» открывают журнал операции. Примеры экранов LG можно увеличить; код берите со своего телевизора.

[LG Developer Mode](https://webostv.developer.lge.com/develop/getting-started/developer-mode-app)

## Необязательный Python для Root в v1.1.0

Root нужен рабочий Python **3.9+** на телевизоре. Установщик проверяет необходимые модули (включая `json` и `fcntl`), блокировки, файловые операции и запуск дочерних процессов: одного номера версии недостаточно. Если подходящий Python уже есть, дополнительной загрузки не будет. Иначе при настройке компьютер или Android скачает проверенный **CPython 3.13.17 для ARMv7 soft-float** и передаст по доверенному SSH; телевизору интернет не нужен. Архив не входит в обычные установщики: загрузка около **26.3 MB**, нормализованная передача по SSH — **51.5 MB**, установленные файлы — **119.3 MB**; для первоначальной подготовки требуется **320 MiB** свободного места. Частная среда не заменяет системные Python, libc или глобальный PATH.

Среде нужны совместимые загрузчик и библиотеки. Требования root SSH, Node.js **8+**, `luna-send` и каталогов приложений и служб webOS сохраняются; No-root Helper нужен Node.js **0.12.2+**. LG UK6540PTD / прошивка 05.50.70 / ARM32 из issue #37 (Python 2.7.12 без Python 3) **не прошёл** аппаратную приёмку с этой средой. Проверки QEMU не подтверждают совместимость ТВ, холодного запуска, пульта или отката. Прежние аппаратные результаты относятся только к указанным в них моделям, прошивкам и сборкам.

Чтобы на компьютере с интернетом подготовить проверенный кэш **без подключения к ТВ**:

```sh
./cytv --language ru --prepare-python-runtime
```

При установке используйте тот же личный каталог данных. Для переноса кэша создайте отдельный новый каталог через `--data-dir /path/to/private-data` и укажите его в обеих командах. Не переносите обычные SSH-ключи и профили в общий кэш. Проверка состояния, диагностика, восстановление и удаление не скачивают Python автоматически. Сохраняйте версии среды, на которые ссылаются установленные обновляторы или восстановление. См. [подробности о Python](../OPTIONAL-PYTHON.md).

## Установка и язык

- **Windows x64:** скачайте `cytv-windows-x64-desktop.zip`, выберите **Извлечь всё** в Проводнике и откройте `cytv-desktop/cytv-desktop.exe`. Сохраните рядом папку `_internal`. Подпись издателя Windows не настроена. Отдельная консольная версия — `cytv-windows-x64.exe`; переименуйте её в `cytv.exe` и используйте `.\cytv.exe` в PowerShell для команд ниже.
- **macOS 13+:** распакуйте `cytv-macos-arm64.zip` для Apple Silicon либо `cytv-macos-x64.zip` для Intel. Перенесите `cytv.app` в «Программы» и откройте; разрешите доступ к локальной сети. Если доверенная загрузка заблокирована, используйте «Конфиденциальность и безопасность → Всё равно открыть». Не отключайте Gatekeeper. Проверка старых систем не завершена.
- **Linux x64:** в Ubuntu 22.04+, Debian 12+ или Mint 21+ установите `cytv-linux-x64.deb` через графический менеджер пакетов, затем откройте Clean Your TV в меню приложений. Для загрузки библиотек может потребоваться интернет. Пакета Linux ARM нет. Отдельный исполняемый файл `cytv-linux-x64` — это CLI; для оконного приложения нужен `.deb`.

[Установщик Android](../../android/README.md) поддерживает все двенадцать языков интерфейса. Справа сверху показан текущий язык; нажмите на него, чтобы выбрать другой. Выбор сохраняется на телефоне.

На Android при подключении остаётся видно выбранное действие обслуживания; ход работы отображается без этапов установки. Используется системный шрифт телефона, подписи и пояснения увеличены.

Оконный мастер сначала выбирает язык системы и сохраняет явно выбранный язык. На телевизоре откройте **Настройки → Язык** и выберите язык либо автоматический вариант, следующий языку телевизора. Настройки языка установщика и телевизора независимы. Все коды приведены в [списке языков](../LANGUAGES.md).

Для отдельно скачанной CLI в macOS/Linux откройте терминал в распакованной папке:

```sh
chmod +x cytv
./cytv --language ru install
```

Выберите телевизор или введите его IP, выберите редакцию и проверьте итоговые параметры. Подтверждайте новую SSH-идентичность только для своего телевизора в доверенной сети; изменение сохранённого ключа блокирует подключение. Root подготавливает восстановление и сразу активирует Home, без пробного периода и подтверждения сохранения. Проверьте стрелки, OK, Home, Назад/Отмена, громкость, выход из ожидания и запуск после полного отключения питания.

Если удаление Root прервано, снова выберите «Удалить» в приложении. Оно проверит сохранённый журнал на ТВ и состояние пакетов перед продолжением; завершённое удаление повторно не запускается. Если операция ещё выполняется, подождите минуту. Если результат не удаётся подтвердить, перезапустите ТВ и повторите проверку; сохраните диагностический отчёт для поддержки.

## Управление и восстановление

Стрелки выбирают плитку, OK открывает её; удержание OK позволяет менять порядок. Короткое «Назад» сохраняет навигацию и диалог выхода приложения. Короткое Home открывает наш экран, пока управление Home активно. В новых сборках удержание «Назад» в течение 1,2 секунды однократно открывает LG Home. Переключатель управления Home и ваши настройки не меняются.

**Новые сборки: трижды коротко нажмите Home за две секунды**, отпуская кнопку между нажатиями. Это возвращает LG Home и останавливает управление без сброса настроек. В старом No-root Helper до версии 0.6.13 включительно вместо этого удерживайте Home около двух секунд. Удержание Home не является аварийным жестом Root.

No-root: Трижды коротко нажмите Home за две секунды, чтобы вернуться в LG Home. Для возобновления откройте Home Helper, выберите «Запустить Helper» и подтвердите. Сохранённый выбор главного экрана не изменится. Root: для возобновления включите **Заменить Home** в настройках Home. **Открыть LG Home** однократно открывает LG Home, не меняя назначение кнопки Home. Чтобы постоянно использовать LG Home, выключите **Заменить Home** или выполните `cytv restore`. Не запускайте оба обработчика одновременно. При повторном сбое оставьте LG Home активным.

```sh
./cytv --language ru status
./cytv --language ru doctor --report
./cytv --language ru restore
./cytv --language ru uninstall
```

После прерывания сначала выполните `status` и сохраните журналы. `restore` возвращает LG Home без удаления приложений; `uninstall` восстанавливает его перед удалением. Данные восстановления Root намеренно остаются: не удаляйте их ради принудительной переустановки. Перед отправкой проверяйте диагностические отчёты; не публикуйте ключи и папки профилей.

## Обновление и удаление

Храните рабочие пакеты и личные резервные копии настроек. При замене пакетов No-root с компьютера сначала остановите Helper и обновляйте без удаления: оно может стереть настройки. Удаление приложения с компьютера не удаляет приложения ТВ. Не ставьте отдельную IPK поверх работающей среды Root; используйте предусмотренный процесс восстановления или переустановки cytv.

В v1.1.0 действие **«Обновить всё»** в Настройки Home → Обновление ПО использует подписанный набор выпуска: Home, Helper и Home Updater для No-root на телевизоре с root; Root Home, Root Updater и среду управления Home и восстановления для Root. Нужны root, Homebrew Channel, рабочие службы установки webOS, Python 3.9+ и Node.js 8+. Телевизор без root по-прежнему обновляется с компьютера.

При новой установке используйте полный установщик стабильного выпуска, чтобы поставить соответствующую переходную версию Home и обновлятор восстановления вашей редакции. **Если Root уже установлен и Root Updater сохранён, обычная переустановка может намеренно блокироваться.** Сначала проверьте `status`, «Восстановление» и существующую транзакцию через соответствующий старой установке процесс восстановления; см. [проверку существующего ТВ](../UPDATES.md#one-time-computer-preparation). Не удаляйте журналы и не обходите эту проверку. Прежнее OTA-обновление одного Home не устанавливает новую инфраструктуру.

Только после подготовки установленных компонентов и проверки состояния восстановления включите **обновление всех компонентов ТВ** в оконном установщике. Для сохранённого root SSH-подключения и редакции Root:

```sh
./cytv --language ru enable-system-updates --edition root --host TV_ADDRESS
```

Это отдельное действие устанавливает фиксированный супервизор и сохраняет установленные компоненты как исходный набор для отката. Оно требует `systemUpdateProtocol = 1` в метаданных установленного Home, не переустанавливает Home и не меняет назначение кнопки. Обычной редакции No-root на телевизоре с root нужны root SSH и соответствующие компоненты, установленные с компьютера; см. [первоначальную настройку](../UPDATES.md#one-time-computer-preparation). Прежнее OTA-обновление только Home **не устанавливает** новый супервизор, Python или инфраструктуру обновляторов. После настройки супервизора конфликтующие старые установщики блокируются; не заменяйте пакеты в обход него.

Обновление системы проверяет и кэширует новый и предыдущий наборы, сохраняет настройки и профили и продолжается после закрытия Home или обновлятора. Восстановление возвращает весь предыдущий набор компонентов и сохранённый профиль. Новые проверки на ТВ, включая освобождение ввода Helper 0.6.19, холодный запуск, полное обновление и откат, ещё не завершены; прежние тесты C3 относятся только к зафиксированным обновлениям одного Home. См. [обновление и восстановление](../UPDATES.md).

Технические инструкции на английском: [оконное приложение](../DESKTOP_INSTALL.md), [CLI](../CLI.md), [No-root](../INSTALL.md), [ручная установка](../MANUAL_INSTALL.md), [восстановление](../RECOVERY.md), [сравнение редакций](../EDITIONS.md).

После подключения cytv читает версии на ТВ и показывает текущую → версию в установщике для Home и Home Helper (No-root) либо Root и Root Updater. Проверьте версии и подтвердите установку. Первая установка, переустановка и понижение версии отмечаются отдельно; `--yes` пропускает подтверждение, но сохраняет вывод версий.

В окне обновления ПО показываются сведения только о текущей или более новой версии. Откройте «Восстановление», чтобы увидеть сохранённую версию для отката или причину его недоступности; «Назад» вернёт к обновлениям.

No-root проверяет ABI оболочки ТВ и допускает 64-битное ядро с подтверждённым ARM32-окружением. Если проверка не прошла, приложите созданный диагностический JSON; ключи и кодовые фразы не публикуйте.

Обновление Home требует подтверждения перед установкой; после запуска проверка выполняется автоматически. Фоновое обновление состояния сохраняет выбранную пультом кнопку.

В обеих редакциях запуск проверяется автоматически; вручную подтверждать работоспособность не нужно. Старый откат только Home возвращает предыдущий пакет Home и его профиль; откат System Updater возвращает весь предыдущий набор выпуска. Восстановление остаётся доступным после подтверждения без ограничения по времени до следующего обновления. Позднейшие изменения настроек могут потеряться; откат требует подтверждения. Обновление и откат No-root с ТВ всё ещё требуют root и Homebrew Channel. После прерывания выполните `status` и проверьте «Восстановление». Неопределённый результат установки блокирует переустановку и откат: сохраняйте журналы, диагностические файлы и версии среды, не удаляйте состояние ради повтора. Продолжайте прерванную операцию cytv только через предусмотренную проверку восстановления.

Экран обновления разделяет версии, состояние и читаемый список изменений. Стрелки вверх/вниз прокручивают изменения, влево/вправо выбирают закреплённые внизу действия. После автоматической проверки запуска Root возвращает ранее включённое управление Home, а No-root сохраняет состояние отдельного Helper. Если управление было выключено или пользователь отключил его обычным либо аварийным способом, оно останется выключенным.

При открытии настроек Home обновления проверяются в фоне. Оранжевая точка на кнопке «Обновление ПО» означает, что доступна новая версия, в том числе требующая установки с компьютера. Во время проверки настройками можно пользоваться.

No-root: откройте Настройки Home → Режим разработчика для автопродления, проверки сессии и диагностики. На основном экране остаются краткий статус и ошибки продления. Назад возвращает в настройки Home. В обеих версиях Язык, Обновление ПО и Настройки ТВ расположены в одном ряду; стрелка открывает соответствующий пункт.

При открытии Home Helper показаны его назначение и состояние. Запуск остановленного Helper требует подтверждения. Home Updater и Root Updater объясняют восстановление; обычные обновления находятся в настройках Home. Восстановление предлагается только при наличии сохранённой версии и требует подтверждения перед заменой Home и его настроек.

Если сразу после настройки супервизора Root показывает `Denied methods call status`, один раз закройте и откройте Home Root, затем снова проверьте обновления. Если ошибка сохраняется, сохраните диагностику и состояние восстановления.

Установку, прерванную до provisioning, можно удалить без ещё не созданного LS2 snapshot; проверенное подтверждение сохраняется для обычного архивирования и переустановки через cytv. Нужен новый драйвер; причина сбоя запуска recovery service на OLED Flex остаётся неустановленной.

## Блокировка прошивки LG в 1.2.0

Некоторые ТВ проверяют обновления раньше; уведомления могут остаться, может потребоваться блокировка на роутере. Homebrew сохраняет настройку после удаления или отката CYTV. При недоступности или неподтверждённом результате проверьте Homebrew и обновите состояние. Объём проверки ТВ указан в записи приёмки.

## Неопубликованный кандидат: установка Root через Homebrew

В исходниках добавлено отдельное приложение **CYTV Installer**, только для **Root**.
В публичном каталоге Homebrew его пока нет. cytv сохраняет No-root и Root на
Windows, macOS, Linux и Android; существующие ссылки ведут на опубликованный cytv.

Нужны уже полученный root, Homebrew Channel с выполнением от root, Node.js **8+**
и рабочий Python **3.9+**. Для поддерживаемого ARMv7/`armv8l` с 32-битным
окружением встроен закреплённый приватный Python, без загрузки на ТВ. Открытие
и статус ничего не устанавливают: явно подготовьте Python, повторите проверку
и просмотрите итоговый план. Нужно **320 МиБ свободного места после установки
Installer**; дополнительное место для установки пакетов на реальном ТВ ещё не
измерено. Поддержка новых моделей и прошивок не подтверждена.

Устанавливаются Root Home и Root Updater; подготовка System Updater выбирается
отдельно. После проверки отдельно включите Change Home. Установка не снимает
аварийную остановку или выключенное состояние. Проверенная текущая установка
сохраняет профиль и восстановление при переходе между cytv и ТВ без переустановки
и сброса. Неизвестная старая инфраструктура требует диагностики; импорт упакованных
настроек предназначен только для новой установки, не для браузерного хранилища.

После прерывания сначала проверьте статус. Продолжение в интерфейсе доступно лишь
для исходного снимка/блокировки с доказанным итоговым состоянием. Иначе нужны
статус, восстановление или диагностика; CLI исходников явно продолжает некоторые
другие подтверждённые этапы. Finish Root setup в cytv не перезапускает незавершённый
процесс установки. Не удаляйте журналы и не повторяйте запрос вслепую.
Homebrew обновляет только Installer; продукт обновляют существующие Updater и
подписанные полные наборы. Удаление Installer оставляет продукт. Полное удаление
выбирается отдельно: оно возвращает LG Home, очищает принадлежащие продукту
записи запуска, сохраняя независимые данные восстановления, архивы и нужный Python.
Все проверки нового пути на ТВ ещё впереди; прежние результаты Root 0.2.0 на C3
не подтверждают установку через Homebrew.

Запуск выполняют принадлежащие продукту приватные обёртки: они проверяют метаданные установленного пакета, но не выполняют его сценарии запуска. Отсутствующий или небезопасный пакет блокирует автоматический запуск; независимое восстановление по-прежнему может вернуть LG Home. При проверке возможна временная приватная копия проверенных файлов без изменения Home или продукта.

[Установка и восстановление (англ.)](../INSTALL.md#candidate-on-tv-root-installation) ·
[Предстоящие проверки на ТВ (англ.)](../development/HOMEBREW-INSTALL-ACCEPTANCE.md)


Для этого кандидата из исходников существующей установке Root нужны проверенное восстановление и новая настройка, чтобы получить исправленную частную среду. Обновление одного Installer её не заменяет. Сохраните записи восстановления и включайте Home только через обычную настройку или параметры.

Только следующий кандидат: в версии No-root откройте Настройки → Режим разработчика → Показать диагностику. Отчёт содержит безопасные коды ошибок хранения и связи с Home, а также фактическую версию сервиса. Просмотр не включает автопродление и не запускает Helper. Ошибка проверки состояния не доказывает остановку Helper. Исправление на C5 пока не подтверждено; [подробности (англ.)](../SETTINGS-DIAGNOSTICS.md).

При открытии фокус пульта переходит на отчёт. Вверх/Вниз прокручивают его; Влево/Вправо или OK возвращают к соседним действиям, Назад — в настройки Home.

**Ещё не выпущено, #82:** если настройка Home отсутствует, явная установка Root может задать LG Home и проверить чтение результата перед завершением подготовки восстановления. Status/doctor ничего не записывает. Запись с неизвестным результатом не повторяется; сохраните данные восстановления. Явная настройка LG Home остаётся после удаления. Проверка на этой прошивке ещё требуется.
